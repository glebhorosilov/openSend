# 🚀 OpenSaidy

**Децентрализованная социальная сеть без единого сервера, работающая поверх GitHub.**

OpenSaidy превращает ваш обычный публичный репозиторий на GitHub в персональный узел соцсети. Никаких центральных баз данных, корпоративной цензуры и платных серверов — ваши посты, подписки и даже дизайн профиля принадлежат только вам.

---

### 💡 В чем главная идея?

Обычные соцсети хранят ваши данные на своих серверах: их могут заблокировать, удалить или изменить правила. В **OpenSaidy** архитектура устроена иначе:

1. **Ваш репозиторий = Ваш аккаунт.** Все посты хранятся в обычном файле `posts.json` внутри вашего GitHub-репозитория.
2. **Полная свобода дизайна.** Как в кастомных профилях Steam или MySpace, вы можете менять внешний вид своей страницы под себя.
3. **Никакого бэкенда.** Клиент работает прямо в браузере (через GitHub Pages) и общается с GitHub напрямую через REST API.
4. **Безопасность.** Для публикации используется ограниченный токен (Fine-grained Token) с доступом только к одному конкретному репозиторию — он хранится исключительно в вашем браузере.

---

### ⚙️ Как это работает под капотом

* **Чтение ленты:** Клиент забирает `posts.json` из репозиториев ваших подписок через `://githubusercontent.com` и собирает единую хронологическую ленту.
* **Публикация:** При создании поста клиент через GitHub Contents API обновляет ваш `posts.json` (кодируя данные в Base64).
* **Кастомизация:** Внешний вид настраивается через локальные/пользовательские темы оформления.
